# 🛠️ DevOps Playground

Welcome to **DevOps Playground** – a personal lab for experimenting, learning, and building with DevOps tools and cloud-native technologies.

> 🚀 This repository is my sandbox to try out real-world DevOps workflows, automate infrastructure, and explore CI/CD pipelines, containerization, and monitoring.

---

## 📁 Repository Structure

| Folder/Path            | Description |
|------------------------|-------------|
| `/terraform/`          | Infrastructure as Code examples using Terraform (e.g., AWS VPC, EC2 setup) |
| `/ansible/`            | Playbooks for automating server provisioning and configuration |
| `/docker/`             | Dockerfiles and Compose setups for containerizing applications |
| `/ci-cd/`              | CI/CD pipelines using GitHub Actions / Jenkins |
| `/kubernetes/`         | Manifests and Helm charts for Kubernetes deployments |
| `/monitoring/`         | Prometheus, Grafana, and alerting configurations |

---

## 🔧 Tools & Technologies

This repo covers hands-on projects with:

- **Terraform** – Infrastructure as Code (AWS, GCP)
- **Ansible** – Server provisioning & configuration
- **Docker** – Containerization
- **GitHub Actions / Jenkins** – CI/CD pipelines
- **Kubernetes** – Container orchestration
- **Prometheus + Grafana** – Monitoring and alerting
- **NGINX** – Web server and reverse proxy
- **Bash & Shell Scripts** – For automation tasks

---

## 🎯 Objectives

- Build reusable DevOps modules and patterns
- Practice cloud-native deployments
- Automate infrastructure provisioning and app deployments
- Set up observability and monitoring tools
- Prepare for DevOps certification exams (AWS DevOps, CKA, etc.)
